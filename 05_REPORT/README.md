# Report & Evidence

Thư mục này lưu các sản phẩm báo cáo và tư liệu minh chứng phục vụ trình bày, đánh giá và bàn giao dự án GIAO THỜI.

## Nội dung

- **Report:** báo cáo tổng kết dự án, mô tả mục tiêu, phương pháp, kiến trúc, kết quả và đánh giá.
- **Screenshots:** hình ảnh giao diện website, Admin và các thành phần hệ thống.
- **Demo:** video hoặc tài liệu minh họa quy trình sử dụng.
- **Test Evidence:** kết quả kiểm thử, log hoặc ảnh chụp thể hiện đầu vào và đầu ra của chức năng.

## Nguyên tắc trình bày minh chứng

- Mỗi minh chứng cần có chú thích về chức năng, bối cảnh và nội dung thể hiện.
- Phân biệt ảnh giao diện, ảnh cấu hình và kết quả chạy thực tế.
- Không sử dụng hình minh họa giả lập để thay thế bằng chứng kiểm thử.
- Không đưa thông tin đăng nhập, API key, access token hoặc dữ liệu cá nhân vào ảnh chụp và tài liệu công khai.
