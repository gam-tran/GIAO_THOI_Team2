# Documentation

## Nguyên tắc đọc tài liệu

- Tài liệu kiến trúc mô tả vai trò và luồng kết nối giữa các thành phần.
- Tài liệu workflow mô tả đầu vào, xử lý và đầu ra của từng quy trình.
- Tài liệu prompt và Skills mô tả logic hướng dẫn AI.
- Tài liệu kỹ thuật website mô tả cài đặt, cấu hình và triển khai.

Khi đối chiếu hệ thống, cần phân biệt cấu hình trong mã nguồn với trạng thái vận hành thực tế của dịch vụ bên ngoài.
