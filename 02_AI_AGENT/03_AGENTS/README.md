# Agents

Lưu trữ tài liệu mô tả từng Agent: mục tiêu, đầu vào, quy trình xử lý, Skills được sử dụng, công cụ được phép gọi, đầu ra và cơ chế phê duyệt.

Nguồn hiện có cần tiếp tục rà soát trong repository giao-thoi-website-v3. Không chia một chức năng thành nhiều Agent riêng nếu mã nguồn/workflow thực tế chưa thể hiện sự phân tách đó.
