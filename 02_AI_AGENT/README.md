# 02 – AI Agent System

Phần này lưu trữ các thành phần phục vụ AI Agent của GIAO THỜI.

## Thành phần
1. Prompt Engineering – chỉ dẫn cho từng nhiệm vụ AI.
2. Marketing Skills – kiến thức và quy trình chuyên môn có thể tái sử dụng.
3. Agent – cách tiếp nhận yêu cầu, lựa chọn Skill/công cụ và tạo đầu ra.
4. Workflows – quy trình điều phối và tự động hóa.
5. Integrations – kết nối dữ liệu và nền tảng bên ngoài.
