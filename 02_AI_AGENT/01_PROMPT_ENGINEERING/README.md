# Prompt Engineering

Lưu trữ Prompt đã sử dụng trong quá trình xây dựng website và vận hành các nhiệm vụ AI.

## Nhóm Prompt dự kiến
- Website building: Prompt hỗ trợ xây dựng và chỉnh sửa website.
- Agent system prompts: chỉ dẫn vai trò, phạm vi và nguyên tắc của Agent.
- Content generation: Prompt tạo nội dung sản phẩm và mạng xã hội.
- Marketing analysis: Prompt phân tích dữ liệu, khách hàng và hiệu quả Marketing.

## Trạng thái
Chưa tập hợp bản Prompt gốc có thể xác minh. Sẽ bổ sung từ lịch sử phát triển và cấu hình thực tế; không tự tạo Prompt rồi ghi nhận là Prompt đã dùng.
