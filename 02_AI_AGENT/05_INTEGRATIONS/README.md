# Integrations

Các tích hợp cần ghi nhận sau khi kiểm tra mã nguồn và cấu hình:
- GA4: đo lường hành vi website.
- n8n: điều phối workflow tự động hóa.
- Supabase: backend và xác thực (cần đối chiếu cấu hình thực tế).
- Social platform APIs: chỉ liệt kê nền tảng đã kết nối và kiểm thử.

Không lưu token, API key hoặc thông tin xác thực trong repository.
